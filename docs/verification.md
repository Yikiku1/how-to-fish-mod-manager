# v1.2 验证范围

项目整理与发布日期：2026-10-15（北京时间）。

## 已执行

- 插件安装、重复安装保护、停用、启用、记录重新读取与卸载。
- ZIP 路径穿越拦截和加载器覆盖前备份；模拟中途失败后恢复已覆盖文件。
- 从真实 Thunderstore 目录获取控制台 Mod，解析 BepInEx 指定版本依赖并按顺序安装到隔离目录。
- curl 失败后切换 PowerShell；全部失败时保留错误码而不输出原始 stderr。
- 240 个中文名称和简介；Tk 实际控件中中英文搜索、切换时保留选中项、空结果清空详情。
- 切换语言不改变原始包数据；作者简介变动时提示译文待更新。
- v1.2 EXE 单独放入临时目录，无外部词典时仍读取 240 条内嵌翻译，并成功获取真实在线目录。

仓库中的 unittest 覆盖可离线重复验证的安装生命周期、ZIP 路径、加载器备份及失败回滚、中文词典和切换。网络自检需手动执行，因为网络可用性会变化。

## 限制

此前 v1.0 网络失败截图未能稳定复现，无法确定唯一根因。v1.1 增加了备用网络方式、TLS 兼容处理、打包环境隔离和诊断信息，并通过真实请求验证。

没有将本工具注入用户实际游戏副本，也未逐一运行第三方 Mod；安装文件成功与游戏内兼容属于不同验证层次。
